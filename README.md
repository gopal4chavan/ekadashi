# Ekadashi static website

This is a dependency-free static site. Upload `index.html`, `styles.css`, and `app.js` to the public folder on Hostinger (usually `public_html`). No Node.js server or database is required.

The current UI includes manual city selection, optional browser geolocation, Smarta/Vaishnava switching, local storage for the selected city, and a small browser-side calendar engine. The sample event data should be reviewed against an authoritative Panchanga before production launch.
